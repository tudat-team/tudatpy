# Atmospheric tidal loading source evidence

The two four-node extracts are copied unchanged from the pinned official Bernese RP03 CE
mirror. Original provider notices are retained. The ATL station coefficients are
transcribed from Bernese manual Figure24.48 solely to test the station parser.
These station numbers do NOT agree with this grid, so they are NOT a numerical
conformance benchmark; see known_reference_limitations.json. Source URLs and full
SHA256 checksums are pinned in sources.json. No upstream software was translated
or copied into production. New C++ code remains under the repository licence.

Bernese manual24.3.17 explicitly gives radial,north,east coefficients in mm, each
cosS1,sinS1,cosS2,sinS2. Figure24.48 declares positive up,north,east. The header and
these sections do not identify geodetic versus geocentric grid latitude. Records
therefore retain latitudeConvention=unspecified; interpolation accepts explicit
provider coordinates without station-position inference.

Ray/Ponte2003 equation2 fits S1 as cos(T-phi) to00/06/12/18UT fields; page1905
identifies the quadrature with06:00. IERS2010 equations19a/b require UT1. This
supports midnight phase origin (+43200seconds for Tudat's J2000-noon epoch),
without an oceanographic S1+180degree shift or a second20-minute correction.

The full source grid retains distinct0/360degree endpoints (maximum difference
0.0008mm). Its Cartesian polar coefficient spread reaches0.0004mm. Strict model
policies reject these differences. The explicit averaging approximation modifies
only model coefficients and records both discrepancies; raw provider data stays
unchanged. Tests use real exact nodes, independent Decimal bilinear values and
analytic synthetic harmonic cases. They do not establish reference-program
agreement while the original interpolation software remains unavailable.

The 14-column source has no grid-count header. The reader verifies a complete
regular lattice within the inferred extent; callers can additionally set
expectedLongitudeCount/expectedLatitudeCount to detect terminal whole-block
truncation. The pinned global provider validation uses361 and181 respectively.
Regional extracts are supported without pretending they cover missing regions.

Regenerate/check the original four-node extract without network access:

```sh
python3 extract_reference_grid.py /path/to/s1_s2_def_ce.dat
python3 extract_reference_grid.py /path/to/s1_s2_def_ce.dat --check
```

The script verifies the pinned full-grid SHA256 before copying original rows.
Figure24.17 of the Bernese manual prints the original lon0/lat90 radial/north
coefficients, which agree with the pinned grid and supply a direct published
node/quarter-day check. This does not resolve the separate station discrepancy.
The manual ATL fixture is a documented transcription, not generated synthesis.

Table7.6 origin-translation checks are generated by optional independent Fortran
complex Fourier synthesis, with Cartesian cross-product local projection. This
uses different numerical expressions and language from the production C++
sine/cosine path. The checks verify the published table and Eq.18 algebra; they
do not prove that an unidentified loading product has the same origin convention.

```sh
python3 generate_origin_translation_reference.py --compiler gfortran
python3 generate_origin_translation_reference.py --compiler gfortran --check
```

The small reference Fortran source is newly written under the repository licence;
no upstream IERS software has been translated. No Fortran compiler/runtime is
needed for ordinary C++ tests or production.

Native-model tests declare lookup and basis separately, exercise both choices
on the same Cartesian ellipsoid point and use a real continuous TAI-axis EOP
converter through the inserted 2016 leap second. Scalar epochs are TDB; phase
uses the model's supplied converter, even when another context clock is given.
Source origin is preserved unless the explicit identified RP03 CE-to-CM policy
is selected. Translation is added in Cartesian coordinates after local rotation.
The first full model checkpoint rejects all d/dTDB velocity/state requests until
shared dUT1/dTDB becomes available; it does not invent zero or implicit rates.
