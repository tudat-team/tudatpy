# Independent corrected IERS solid Earth tide reference

These fixtures were generated by executing the IERS Conventions Center's
unmodified `DEHANTTIDEINEL.F` and its dependencies. No Tudat output was used as
an expected value. The first two rows reproduce the published 2009 and 2012
header examples to the last printed digit; the remaining sixteen use
controlled ECEF Sun/Moon vectors and stations around the globe. They cover
non-midnight UTC, both hemispheres, equatorial and high-latitude stations,
different leap-second offsets, negative J2000 epochs across calendar midnight,
exact UTC noon and the TT J2000 zero epoch. Controlled vectors intentionally are not astronomical
ephemerides: they isolate the displacement formula, geometry and time arguments.

## Provenance

- Authoritative Chapter 7 software and correction history:
  https://iers-conventions.obspm.fr/chapter7.php
- Reference main routine:
  https://iers-conventions.obspm.fr/content/chapter7/software/dehanttideinel/DEHANTTIDEINEL.F
- Main routine revision: 19 December 2016, accounting for the 2017 leap second.
  It includes the 17 May 2013 correction to the repeated division of fractional
  hours by 24 (announced 10 June 2013).
- Source retrieval date: 14 October 2026. `sources.json` pins all eleven source
  files by SHA-256, including the SOFA-supplied `DAT.F` and `CAL2JD.F`.
- Reference executable: GNU Fortran 15.2.0, conda-forge build 15.2.0-19;
  compilation flags `-O0 -ffixed-line-length-none`, one compiler process.

The IERS updated chapter page describes itself as under development. These
fixtures use its explicitly corrected Chapter 7 solid Earth tide software,
not the pre-correction routine from the official 2010 tarball. The original
routine omits the permanent-tide uncorrection (Step 3); these fixtures do too.
`inputs.csv` contains UTC calendar dates and hours plus ECEF vectors in metres.
`expected.csv` contains UTC/TT seconds since J2000, Cartesian displacement in
metres, and separately evaluated diurnal/long-period Step 2 displacements.
`fixtures.h` is generated from those tables for a test without runtime downloads.

## Reproduction

Use Python 3 and GNU Fortran. Choose a cache outside the repository; all downloaded
sources and executables stay there. This script makes no uploads or remote writes.

```sh
python3 generate.py --reference-dir /absolute/local/reference-cache --download
python3 generate.py --reference-dir /absolute/local/reference-cache --check
```

Pass `--compiler /absolute/path/to/gfortran` if the compiler is not on `PATH`.
The script verifies source checksums before compiling and checks the two published
benchmarks independently before writing any fixtures. `--check` compares the
recomputed decimal CSV and generated C++ table byte for byte with their committed
versions. A different compiler may require comparing the numeric values when its
last decimal digit differs; the published benchmark check allows 1e-15 metres.

`reference_driver.f90` is an original Tudat test driver. The downloaded main
routine calls `DAT`/`CAL2JD`, but the downloaded SOFA files define
`iau_DAT`/`iau_CAL2JD`. The two separately named link adapters forward arguments
without altering any reference source or numerical algorithm.

## Regression and numerical conventions

The production station model now uses the corrected STEP2DIU/STEP2LON polynomials,
including the reference precession term in lunar longitude. Polynomial centuries
use TT; fractional hours use UTC. Its public time argument retains the existing
TDB approximately TT convention. The fixtures provide exact TT input epochs so
the reference comparison does not include that approximation; an explicit time
context for separate TDB, TT and UT1 is future API work. The reference itself uses
UTC hours rather than a separately supplied UT1 value. Both full-model comparisons
use a 1e-9 metre absolute tolerance per Cartesian component, including near-zero
components. One uses the default production callback and one preserves an
explicit independent reference-polynomial callback.

A diagnostic using only the standalone SOFA library, not Tudat, identified why the
previous generic SOFA default disagreed with DEHANT. At 2020-02-29 15:37:30 UTC,
the six SOFA-minus-DEHANT argument differences `[tau,s,h,p,N-prime,p-s]` were
approximately `[-2.3424,-1014.5493,+0.000507,0,+0.000002,0]` arcseconds.
The lunar longitude difference is the reference's precession polynomial
`(1.396971278 + (0.000308889 + (0.000000021 + 0.000000007*T)*T)*T)*T` degrees.
The previous argument convention changed Step 2 by up to 28.025 micrometres in
this fixture set. Adding just that precession term reduced the difference to
0.107 micrometres; the remaining difference comes mainly from tau's GMST/time
convention. Therefore the station-specific default reproduces the complete
reference series rather than widening a tolerance. The generic SOFA Doodson
routine is preserved for other consumers.
